parameter).

If the fact that it is impossible to call a different selection

principle for each layer proves to be a great obstacle, an auxiliary
construction can be used. We calculate as many variant groups (only one
variant per variant group) as the number of layers to be contained in
the score. Admittedly, it is then impossible to work out a common
harmony for ail the layers, but on the other hand a different selection
principle can then be used for each layer (and each parameter).
