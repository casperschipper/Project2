# Ways in which PR2 is different

* Tendency mask do not act on continuous ranges, they work always over a section of a list. Values are thus quantized.
* PR2 is very instrumental: it thinks of music as instruments playing notes. But otherwise it allows for a lot of flexibility:
  * Non-12 octave divisions
  * Playing techniques
  * Arbitrary durations and metres
* It is a very serial program (series is used throughout), however it also has generators that are the exact opposite (forced repetition, or weighted choice generations)
* Hierarchy: selected parameters can prohibit 
* It has some Combination and Union concepts which are unique to PR2 and allow the composer to have multiple groups of material.
